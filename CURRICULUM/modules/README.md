# Bài giảng từng module

Mỗi module được giao thành một file riêng: `MODULE_NN_<tên>.md` (ứng dụng)
hoặc `THEORY_TN_<tên>.md` (lý thuyết).

## Thứ tự giao — theo `../03_FINAL_ROADMAP.md`

| # | File | Trạng thái |
|---|---|---|
| 1 | `MODULE_00_learning_roadmap.md` | đã giao trong hội thoại, chưa xuất file |
| 2 | `MODULE_02_linux.md` | **tiếp theo** |
| 3 | `THEORY_T1_molecular_biology.md` | chờ |
| 4 | `MODULE_01_molecular_biology_ngs.md` | chờ |
| 5 | `MODULE_03_command_line.md` | chờ |

Pharma/cosmetics examples · Oxford Nanopore relevance · Common mistakes · Troubleshooting ·
